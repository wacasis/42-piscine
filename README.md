# Libft et exercices de la Piscine 42

Dépôt regroupant des exercices de programmation en langage C réalisés dans le cadre de la Piscine 42 et du projet Libft.

## Contenu

- **Fonctions Libft :** `ft_atoi`, `ft_strdup`, `ft_split`, `ft_strcat`, `ft_strcmp`, `ft_strcpy`, `ft_strncmp`, `ft_strncpy`, `ft_strstr`, `ft_substr`, etc.
- **Exercices de la Piscine :** `aff_a`, `aff_z`, `ft_countdown`, `ft_putnbr`, `ft_swap`, `ft_sort_int_tab`, `ft_convert_base`, `rot_13`, etc.
- **Fichiers de base :** `libft.h` et fichiers sources associés.
